# Sinnoh Pokémon - Checkpoint 5 WEB

## 📦 Instalação das Dependências

### Pré-requisitos

Clone o repositório:

```bash
git clone <URL_DO_REPOSITORIO>
```

Acesse a pasta do projeto:

```bash
cd checkpoint-5-webdev-1ESR
```

Instale as dependências do projeto:

```bash
npm install
```

Instale a biblioteca da API (axios)

```bash
npm i axios -S
```

---

## ▶️ Como Executar o Projeto

Após instalar as dependências, execute o servidor de desenvolvimento:

```bash
npm run dev
```

O projeto estará disponível no endereço:

```text
http://localhost:3000
```

Para interromper o servidor, utilize:

```text
Ctrl + C
```
